# SOP-IT-003: Approved Software Installation

**Category:** Endpoint management  
**Owner:** IT Service Desk  
**Review cadence:** Every 12 months

## Purpose

Define the approved process for installing software on a corporate device.

## Procedure

1. Confirm that the software is listed in the approved software catalog.
2. Check whether the user has a valid business justification and the required license.
3. Submit the installation request through the approved service workflow when approval is
   required.
4. Install the software from the managed company portal or another source approved by IT.
5. Apply the latest available security updates.
6. Confirm that the application launches and that the user can complete the required task.

## Prohibited actions

- Do not download cracked, pirated, or unlicensed software.
- Do not bypass endpoint security controls.
- Do not install software from an unknown link supplied in an email or chat.
- Do not use administrator credentials obtained from another person.

## Escalation

Create a support ticket if the software is not in the catalog, installation fails, a license is
unavailable, or security software blocks the installation. Include the application name,
version, device name, error message, and business justification.
