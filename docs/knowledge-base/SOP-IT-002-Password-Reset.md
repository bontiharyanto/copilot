# SOP-IT-002: Corporate Password Reset

**Category:** Identity and access  
**Owner:** IT Service Desk  
**Review cadence:** Every 12 months

## Purpose

Provide a safe procedure for resetting a forgotten or expired corporate password.

## Procedure

1. Open the approved self-service password reset portal.
2. Enter the corporate username.
3. Complete the configured identity verification and MFA challenge.
4. Create a new password that meets the displayed corporate password policy.
5. Sign in again on the affected device and update any approved password manager entry.
6. Allow a few minutes for the new password to synchronize across Microsoft 365 services.

## Escalation

Create a support ticket if identity verification fails, the account is locked, or the new
password does not work after synchronization. Include the username, error message, and time of
the attempted reset.

## Security note

Service Desk staff must not ask users to disclose passwords or MFA codes. Verify identity only
through the approved verification process.
